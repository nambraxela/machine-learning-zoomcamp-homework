# Machine Learning Zoomcamp — Homework

My solutions to assignments from the [DataTalks.Club Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp). I am taking the course alongside my Industrial Engineering and Management studies at Lund University to develop practical skills in data analysis and machine learning.

## Contents

- **01-intro:** Data exploration and manipulation with Pandas and NumPy.
- **02-regression:** Linear regression, missing-value handling, regularization and RMSE evaluation.
- **03-Classification:** Logistic regression, categorical encoding and feature selection.
- **04-evaluation:** ROC-AUC, precision, recall, F1 scores and cross-validation.

## Tools

Python, Pandas, NumPy, Scikit-learn, Matplotlib and Jupyter Notebook.

These notebooks document coursework and my learning process. Assignment instructions and datasets are provided by DataTalks.Club.
